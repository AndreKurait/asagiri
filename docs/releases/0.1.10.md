## New
- **Asagiri for Linux has a window**: the `asagiri` package now brings Asagiri's app window, with an entry and icon in your app menu. `asagiri ui` opens it, and says so plainly when there isn't one (the headless `asagiri-lite` package).

## Fixed
- **Start works on Windows while WSL is still booting.** On a fresh install the window could sit on "Linux VM Stopped" with Start doing nothing; it now starts the engine once WSL is ready.
- **Diagnostics no longer crashes the Windows window**, so Send report works again.
- **Windows Defender no longer flags Asagiri as a trojan.** Asagiri for Windows used to carry its setup scripts inside the app and run them as encoded PowerShell, which Defender's heuristics took for malware. The scripts are now plain files beside Asagiri, and Asagiri asks Windows for approval itself.

## Better
- **The app icon** fills more of its tile, so it reads better in the Dock, taskbar and app menus.
- **Licences**: every download now carries Asagiri's licence and a NOTICE file listing the open source components inside it.
