What these numbers cover

The Linux check warms both engines, then alternates 400 requests of each kind between the baseline and the tested commit. Daemon system calls use 20 additional container lifecycles; already-running agent processes are outside that trace. The gate compares medians, daemon memory and system calls against the paired baseline; p95 and binary size are tracked without a failure threshold.

Shared runners have noise. Absolute values are observations on that runner, and a failed comparison needs investigation. These checks do not measure Mac VM startup, Rosetta, Windows WSL, cold image downloads or application workloads.

The dashboard shows the latest 500 archived runs; the raw archive retains every published record. A main push measures its resulting commit. Intermediate commits in a multi-commit push are not measured separately. PR results remain in their GHA artifacts.
