DOWNLOAD & OPEN

The Mac app.

Choose your Mac. Open the DMG, drag Asagiri into Applications, then open Asagiri.

Download for Apple Silicon ↓ Download for Intel ↓

macOS 14 or newer. Apple Silicon means an M-series chip. Check Apple menu → About This Mac.

COPY, PASTE, INSTALL

Prefer the terminal?

This command chooses your architecture, verifies the download, and installs the app.

curl -fsSL https://andrekurait.github.io/asagiri/install.sh | sh

Open Asagiri from Applications after installation.

First launch: current apps are not notarized by Apple. If macOS asks for approval, open System Settings → Privacy & Security → Open Anyway. The installer checks the app’s checksum and code signature; it does not change Gatekeeper settings.
ALREADY USE HOMEBREW?

Install from our tap.

brew install --cask andrekurait/asagiri/asagiri

Homebrew follows the recommended channel. Open Asagiri when the install finishes.

KEEP IT CURRENT

Update when you’re ready.

brew upgrade --cask andrekurait/asagiri/asagiri

For a direct install, quit Asagiri and rerun the install command. Container data stays in place.

AMAZON LINUX 2023 · X86_64 & GRAVITON

One setup command.

Configure the signed RPM repository, install Asagiri and its Docker tools, then start the engine.

curl -fsSL https://andrekurait.github.io/asagiri/install.sh | sh

Run as the account that will use containers. Setup asks for sudo and grants that account container access, which is equivalent to root access.

TRY YOUR FIRST CONTAINER

You know the commands.

docker --context asagiri run --rm alpine echo hello
docker --context asagiri compose version
docker --context asagiri buildx version

Runs directly on the Linux host. An existing Docker installation and your selected context keep their settings.

UPDATES THROUGH DNF

A normal package upgrade.

sudo dnf --refresh upgrade asagiri

Running containers continue using the existing engine. Run sudo systemctl restart asagiri when ready to use the new binary. This stops its containers; restart policies control which start again.

BUILDING AN AMI OR FLEET IMAGE?

Install without starting it.

curl -fsSL https://andrekurait.github.io/asagiri/install.sh | sh -s -- --no-start

Configure access after boot with sudo asagiri host-access ec2-user. Signed package verification stays enabled.

A few useful details.

Verify downloads and package signatures

Each GitHub release includes SHA256SUMS, its source commit, and GitHub build provenance. The DNF repository adds an RPM signature and verifies every original release before publishing it. The setup command pins the RPM public key. Read the verification details ↗

Preview and stable releases

Main builds publish tested prereleases. Version tags publish stable releases. Recommended installs switch to stable releases when one is available. Select “Latest main preview” to keep testing main builds.

Remove Asagiri

With Homebrew: brew uninstall --cask andrekurait/asagiri/asagiri. For a direct Mac install, quit the app and move it to Trash. On Amazon Linux: sudo dnf remove asagiri. These steps preserve your container data.

Windows and other Linux distributions

Windows MSI installers, Debian packages, RPMs, and static Linux binaries are on the release page ↗. Follow the platform notes in the release before installing.
